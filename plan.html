V EDIT. 직접 고치는 홈페이지

목적
영상의 수정모드 메시지를 메인에서 체험하듯 보여주고, 관리자 팝업 디자인까지 한 흐름으로 묶는다. (요청: 관리자페이지 팝업 디자인 · 직접 수정 가능한 커스텀 홈페이지 필수)
카피
문구 하나 바꾸는데 며칠씩 기다리셨나요?이제, 직접 고치세요.브이웹 홈페이지는 브랜드에 맞춰 만든 커스텀 홈페이지입니다. 관리자 로그인 한 번이면 보고 있는 화면에서 바로 고치고, 바로 반영됩니다.
구성
  1. 인트로 — 질문 → 해답 (영상 00:02~00:03)
  2. 단계 목록 5 + 브라우저 목업 — 01 수정모드 켜기 · 02 글자 수정 · 03 이미지 교체 · 04 대표번호 일괄 수정 · 05 팝업 디자인
  3. 카드 4 — 연결 링크 · 메인 슬라이드 · 매장 목록 (화면에서 바로) / 디자인 관리 (관리자: 팝업레이어 · 배너 · 로고 · 메뉴 · 레이아웃 · 워터마크)
  4. 저장 → 저장 완료 — "클릭 한 번이면, 사이트에 바로 반영."
모션
PC 단계 전환 핀 1개 (단계당 0.8뷰포트) — 핀 진행도로 단계를 바꾸고, 단계마다 커서가 클릭 · 타이핑 · 모달 적용을 시연. 왼쪽 진행선이 채워지고, 단계를 누르면 해당 위치로 스크롤.
모바일 핀 없음 — 목업이 화면에 들어오면 자동 재생(단계 끝 + 1.6초 후 다음), 탭 터치로 이동, 화면 밖이면 일시정지.
근거 기능
  • 수정모드: 텍스트 · 굵게/기울임/취소선 · 색상(#코드) · 크기 ± · 서식 지우기
  • 사진 교체 (긴 변 1200px 자동 리사이즈)
  • 링크 수정 · JSON 슬라이드 추가/삭제/순서
  • FAQ · 매장 행 추가 (주소 → 좌표 자동 변환)
  • ☎ 대표번호 일괄 수정
  • 팝업레이어관리: PC/모바일 따로 설정
  • 표시 방식 슬라이드 · 나열식 · 스택형
  • 배경 효과 없음 · 어둡게 · 블러
  • 다시 보지 않음 시간 · 노출 기간 · 기기 · 페이지
  • 유튜브 링크 자동 임베드
표현 주의
수정모드는 프로젝트마다 적용하는 패키지라 "브이웹 홈페이지에 적용"으로 표현. 수정 이력/버전 되돌리기는 없으므로 카피에서 사용하지 않음.

V SEARCH. AI가 읽는 홈페이지

목적
SEO → AEO → GEO 흐름을 "사람이 보는 화면 vs AI가 읽는 화면" 비교로 한 번에 이해시킨다. (요청: AEO · GEO · SEO, JSON-LD, 사이트맵, AI가 읽을 수 있는 홈페이지)
카피
검색창 대신 AI에게 묻는 시대, 우리 홈페이지는 AI가 읽을 수 있나요?정리된 데이터는 AI 답변에 그대로 인용됩니다.
구성
  1. 비교 — 매장 카드(사람) ↔ JSON-LD @graph 코드(AI), 가운데 "화면과 1:1 일치" 체크 5개
  2. AI 답변 예시 — 질문 → 생각 중 → 답변 스트리밍 → 출처 칩
  3. SEO · AEO · GEO 카드 3 + 키워드 칩 (sitemap.xml · robots.txt · JSON-LD · FAQPage · 매장 ItemList · Open Graph · RSS · 서치어드바이저 · 서치콘솔 · alt 설계)
모션
코드 줄이 흐린 상태에서 위부터 또렷해짐 → 매장명 · 주소 · 전화 · 영업시간 · FAQ 순으로 양쪽 동시 하이라이트 + 체크. 답변은 단어 단위로 흘러나옴. PC 카드는 자기장(근접) 호버.
근거 기능
  • JSON-LD 플레이북: 고객사 Organization + WebSite + 제작사(브이웍스 · 브이웹 · 브이인더웹)
  • 매장 목록 + 좌표, FAQPage — 게시판과 같은 데이터
  • 화면에 보이는 사실만 넣는 원칙
  • 사이트맵 플레이북: 동적 sitemap · robots Sitemap 줄 · 구글/네이버 제출
  • 관리자 사이트 정보 · SEO: 메타 · OG · 소유확인
  • ROBOTS 설정 · RSS
  • 시맨틱 마크업 · 이미지 alt 설계 규칙
표현 주의
JSON-LD · 동적 사이트맵은 플레이북으로 제작 시 적용하는 항목 → "제작 단계에서 설계합니다"로 표현. llms.txt · IndexNow · hreflang은 현재 제공 범위가 아니어서 넣지 않음.

실제 메인 적용 메모

  • 클래스는 vs01 ~ vs05 접두어 — 기존 메인 con2 ~ con9와 겹치지 않음.
  • 현재 메인은 GSAP 3.11.4 + ScrollTrigger 3.6.0으로 버전이 서로 다름 → 3.13.0으로 통일하고 ScrollToPlugin을 추가하는 것을 권장.
  • 스크립트는 jQuery 1.12에서도 동작하는 문법만 사용 (자기장 효과 함수).
  • 시안 상단바 · 커버 · 하단 안내(.dh · .cv · .df)는 데모용이라 이식 대상이 아님.
  • 이미지 파일 없이 CSS · SVG로만 구성 — 실제 적용 시 디자인 시안 이미지로 교체 가능.
  • 화면 속 브랜드(모노브루) · 번호 · 수치는 모두 설명용 예시.
